Be unreasonably ambitious.

Apply this to the task given with this invocation, or to the current task when none is given. Aim for the best result that can exist, not the first result that works. For this task, this bar takes precedence over the smallest-change rule and the limit on scope. The rules on safety, secrets, pushes, and confirmation stay in force. Verify the result against this bar before you stop.

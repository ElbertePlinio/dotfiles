Resolve the repository with `chezmoi source-path`. The command implementation is `dot_local/bin/executable_agent-config-sync`; validation lives in `scripts/check-agent-config-sync.sh`. Read these sources when command behavior matters rather than assuming the installed CLI matches.

`agent-config-sync check` validates source templates and skill distribution. `check-live` performs read-only live checks. `doctor` diagnoses local harness configuration. `apply` validates the source, runs a full `chezmoi apply`, and checks live state. chezmoi runs `scripts/apply-guard.sh` first on every full apply. The guard stops the apply when a target holds a live edit made since the last apply, a file that existed before chezmoi managed it, or a live directory that a file or link would replace. During an apply, chezmoi runs the guard only as a script. Never give a full apply `--keep-going`, or an `--include` or `--exclude` that leaves out scripts. The first ignores the guard's failure, and the others skip the guard. Do not repeat checks already completed by apply on unchanged source.

`sync` fast-forwards clean dotfiles on main and clean AgentMemory, then applies. Exit 76 means the dotfiles update was blocked. Sync can leave dirty or unavailable AgentMemory unchanged and reports that separately. Use it only when repository updates are authorized, not for local source edits.

There is no harness scope argument. Never use `agent-config-sync apply pi`. For a harness-only request, select explicit live paths from the corresponding source and declared skill links, review their scoped diff without exposing credentials, run `agent-config-sync check`, then `chezmoi apply -- <explicit-live-paths>`. A scoped apply skips the apply guard, and `chezmoi status` cannot show a file that chezmoi never wrote. Run `bash "$(chezmoi source-path)/scripts/apply-guard.sh"` first, and stop if it lists any path you intend to apply. Finish with `agent-config-sync check-live` and any missing relevant harness check. Preserve shared templates and other harnesses. Report unrelated validation failures rather than widening scope to fix them.
